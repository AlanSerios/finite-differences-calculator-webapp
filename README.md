# Finite Differences Calculator

**Live Demo:** [Insert your Vercel link here, e.g., https://finite-differences.vercel.app]

A Flask web application for calculating and visualizing numerical derivatives using Forward, Backward, and Central Finite Difference methods.

## Prerequisites

- Python 3.8 or higher installed on your machine.

## How to Run Locally

1. **Open a Terminal** (or Command Prompt).
2. **Navigate** to this project directory:
   ```bash
   cd path/to/finite-differences-app
   ```
3. **Install the dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Flask application**:
   ```bash
   python app.py
   ```
5. **Open your web browser** and navigate to:
   http://127.0.0.1:5000

## Features
- Real-time MathJax LaTeX rendering
- Interactive Secant & Tangent plotting via Chart.js
- Local Storage Calculation History
- Dynamic H-value and X-value Sliders
